## Step 1 – Workspace

**Done:**

- Nx workspace generated with `create-nx-workspace@24.0.6` (empty template, pnpm, Nx Cloud skipped) and copied into this folder; existing `docs/` kept as it was.
- `git init` on branch `main`; this log created.

**Files:**

| File                             | Purpose                                                                  |
| -------------------------------- | ------------------------------------------------------------------------ |
| `package.json`                   | Workspace root: dev tools with exact versions, Node and pnpm pins        |
| `pnpm-workspace.yaml`            | pnpm workspace folders (`apps/*`, `libs/*`) and approved install scripts |
| `pnpm-lock.yaml`                 | Exact resolved dependency tree (generated by pnpm)                       |
| `nx.json`                        | Nx settings; local cache only, no Nx Cloud                               |
| `tsconfig.base.json`             | Shared TypeScript settings (`strict: true`)                              |
| `tsconfig.json`                  | Root TypeScript project; projects are added as references later          |
| `.prettierrc`, `.prettierignore` | Formatting rules and ignored files                                       |
| `.gitignore`                     | Files git never tracks (`node_modules`, `dist`, Nx cache)                |
| `.gitattributes`                 | LF line endings on every machine                                         |
| `.nvmrc`                         | Node major version (24)                                                  |
| `.vscode/extensions.json`        | Recommended editor extensions (Nx Console, Prettier)                     |

**Decisions:**

- **No Nx Cloud, no remote cache.** `nx.json` has no `nxCloudId`; caching stays in `.nx/cache` on each machine.
- **Only core template files kept.** The template also added AI-agent config folders, an `AGENTS.md`, a README advertising Nx Cloud and a CI workflow that runs on Nx Cloud; these were not copied.
- **Exact versions** for all dev dependencies (no `^` / `~`). Nx bumped from the template's 24.0.0 to 24.0.6 (latest patch).
- **Install scripts allowed only for `nx` and `@swc/core`** (`allowBuilds` in `pnpm-workspace.yaml`). pnpm 12 blocks dependency install scripts by default and fails with `ERR_PNPM_IGNORED_BUILDS`; these two need theirs to fetch their native binary for the current OS.
- **Prettier ignores** `pnpm-lock.yaml` (generated by pnpm).
- **Repository:** public GitHub repository, branch `main`.

**Verified:** `pnpm install` succeeds, `pnpm nx --version` reports 24.0.6, `pnpm nx graph` opens an empty graph, `pnpm prettier --check .` passes.

**Open issues:** none.
